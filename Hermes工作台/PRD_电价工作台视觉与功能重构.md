# PRD & 架构设计：SolarPrice-Insight 电价工作台视觉与功能重构

## 1. 项目背景与目标
针对现有电价工作台在视觉层面上扁平生硬、筛选选项展开不便，以及缺少面向工程方案汇报的高清图表导出和最近 12 个月历史回溯数据导出功能的问题，本次重构将：
1. **视觉全面对齐高水准能源数据平台（如 energydc.cn）**：采用微毛玻璃（Glassmorphism）、大圆角、低饱和度专业分时色谱、全局等宽数字（`font-variant-numeric: tabular-nums`）与精致微投影。
2. **首行全局筛选器重构**：将省份、执行月份、用电类别、电压等级全面升级为带下拉箭头的全量展开选择器（Dropdown Popovers），省份支持 31+ 省份拼音/汉字实时检索与区域分组，月份支持年份切换与 12 个月全量矩阵。
3. **24H 连续分时状态谱带区间化**：明确按 `00-01` 至 `23-24`（即 `00:00~01:00` 至 `23:00~24:00`）连续小时区间排布，配备高精度悬浮 Tooltip。
4. **24H 电价走势折线图圆点分时上色**：曲线上每个小时的数据圆点颜色与该小时的分时类型图例严格对应（尖红、峰橙、平蓝、谷绿、深紫）。
5. **落地两大导出下载引擎**：
   - **24H 走势与谱带高清截图下载（PNG）**：基于 `html2canvas` 实现 2x 超采样无水印高清合成导出。
   - **当前省份最近 12 个月电价与时段数据下载（Excel）**：基于 `xlsx`，默认按当前月份回溯导出连续 12 个月（不足则拉取已有历史 12 个月）的双工作表（`12个月电价与成本分项` + `24小时逐时时段表`）。

## 2. 详细技术实现方案

### 2.1 全局样式与色盘规范
- **文件**：`index.html`, `constants.tsx`
- **样式**：
  - 全局加入 `* { font-variant-numeric: tabular-nums; }`。
  - 分时颜色常量统一：
    - 尖峰（sharp）：`#e11d48` (Rose-600), 背景 `bg-rose-50`, 边框 `border-rose-200`
    - 高峰（peak）：`#d97706` (Amber-600), 背景 `bg-amber-50`, 边框 `border-amber-200`
    - 平段（flat）：`#2563eb` (Blue-600), 背景 `bg-blue-50`, 边框 `border-blue-200`
    - 低谷（valley）：`#16a34a` (Emerald-600), 背景 `bg-emerald-50`, 边框 `border-emerald-200`
    - 深谷（deep）：`#9333ea` (Purple-600), 背景 `bg-purple-50`, 边框 `border-purple-200`

### 2.2 侧边栏（Sidebar）重构
- **文件**：`components/Sidebar.tsx`
- **内容**：保持 5 个电价工作台核心导航（电价与时段总览、跨省横向对比、分时规则查看、综合电价、系统设置），加入毛玻璃与圆角高亮。

### 2.3 主工作台（Dashboard）重构
- **文件**：`components/Dashboard.tsx`
- **主要模块**：
  1. **Header 筛选工具栏**：
     - `ProvinceSelector`：点击展开 Popover，含实时搜索框、全量省份网格。
     - `MonthSelector`：点击展开 Popover，含年度切换与 1~12 月全量矩阵。
     - `CategorySelector` & `VoltageSelector`：全量展开菜单。
     - 导出按钮：`导出该省近 12 个月电价与时段 (Excel)`。
  2. **4 大关键指标毛玻璃卡片**：
     - 尖峰电价、最低谷电价、最大峰谷套利价差、综合均价。
  3. **24H 时段谱带与电价走势图主 Card**：
     - 右上角内置 `下载图表截图` 按钮。
     - 24 列 `00-01` ~ `23-24` 谱带网格与 Hover 气泡。
     - Recharts / Canvas 走势曲线，`dot` 渲染自定义分时彩色圆点。
  4. **下半区 6+2 成本构成拆解表与储能策略排程**。

### 2.4 导出引擎封装
- **截图导出**：截取 24H 谱带主容器，动态隐藏自身按钮并生成高清 PNG。
- **Excel 导出**：根据当前选中的 `province`、`category`、`voltage_level`，从 `tariffs` 数据库与 `timeConfigs` 规则中提取最近 12 个月真实记录，生成结构化双 Sheet Excel。

## 3. 测试与验证策略
1. 单元测试：`npm run test` 确保所有 32 个测试套件及现有测试通过。
2. 构建检查：`npm run build` 确保 TypeScript 类型零错误，打包顺利。
3. 交互实测：在 Hermes Desktop 中验证下拉筛选展开、搜索、截图下载与 Excel 导出。
