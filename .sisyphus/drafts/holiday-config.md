# Draft: 法定节假日配置功能

## 需求背景
用户希望在消纳计算程序的工作作息配置中增加法定节假日的配置功能。

## 当前代码结构（已研究）

### 相关文件
- `types.ts` - TimeConfig、TimeRule、TimeType 类型定义
- `services/db.ts` - RxDB 数据库 schema 定义
- `services/consumptionAlignedService.ts` - 消纳计算核心逻辑，包含 getDayType 判断工作日/休息日
- `utils/timeConfigResolver.ts` - TimeConfig 解析与按省/月份选取
- `components/TimeConfig.tsx` - 工作作息配置 UI
- `components/TimeConfigMatrix.tsx` - 24小时 × 12月网格编辑器

### 当前日期类型判定逻辑
位于 `consumptionAlignedService.ts` 的 `getDayType` 函数：
- workPattern 参数：'双休' | '单休' | '无休'
- 基于 BASE_YEAR=2021 的星期判定
- 只区分 'workday' 和 'restday'，**无法识别法定节假日**

### 现有限制
1. 无节假日数据存储
2. getDayType 仅基于星期几判断，不考虑实际节假日
3. 节假日调休（补班）未处理

## 需求确认（已完成第一轮）

### 已确认需求
- [x] 法定节假日数据来源？→ **手动配置**（用户在 UI 中添加/编辑，存储在本地 RxDB）
- [x] 是否需要支持调休/补班日？→ **不需要**（只标记假日，不处理调休）
- [x] 节假日的电价计算规则？→ **独立规则**（节假日有单独的负荷等级或电价规则）
- [x] 节假日是否需要按省份区分？→ **全局通用**（所有省份共用一套节假日配置）

### 已确认需求（第二轮）
- [x] 负荷等级：**新增 Level D**（节假日专用等级，可单独配置负荷比例 R_D）
- [x] TOU 时段：**不需要独立配置**（节假日使用与工作日相同的 TOU 时段划分）
- [x] UI 入口：**嵌入现有页面**（在 TimeConfigMatrix 编辑器中增加节假日配置区域）
- [x] 年份管理：**单年配置**（只配置"当年"的节假日）

### 已确认需求（第三轮）
- [x] R_D 配置位置：**WorkSchedule 中**（与 R_B/R_C 一起，在消纳计算页面的"工作作息"区域配置）
- [x] 日期格式：**MM-DD 格式**（只存月-日，每年复用）
- [x] 默认数据：**预填充**（元旦、春节、清明、劳动节、端午、中秋、国庆等）
- [x] UI 交互：**列表输入 + 日期范围**（支持多种节假日的起始-结束日期选择）

### 关键设计决策
- **全局节假日库**：维护一个全局的节假日定义列表（名称 + 日期范围）
- **项目级多选**：在消纳计算时，用户可勾选本次计算使用哪些节假日

### 已确认需求（第四轮 - 最终）
- [x] 节假日库编辑入口：**消纳计算页面内**（在 WorkSchedule 配置区域增加"编辑节假日库"按钮）
- [x] 存储方式：**RxDB**（创建 `holidays` 集合，与 TimeConfig、Tariff 一致）

## 技术决策（已确定）

### 数据结构设计
```typescript
// 全局节假日定义（存储在 RxDB holidays 集合）
interface HolidayDefinition {
  id: string;
  name: string;           // 如 "春节"、"国庆节"
  startDate: string;      // MM-DD 格式，如 "01-31"
  endDate: string;        // MM-DD 格式，如 "02-06"
  isDefault: boolean;     // 是否为预填充的默认节假日
  updated_at: string;
}

// WorkSchedule 扩展
interface WorkSchedule {
  workStartHour: number;
  workEndHour: number;
  workPattern: '双休' | '单休' | '无休';
  R_B: number;
  R_C: number;
  R_D: number;                    // 新增：节假日负荷比例
  selectedHolidayIds: string[];   // 新增：选中的节假日 ID 列表
}
```

### 计算逻辑修改
- `getDayType` 函数扩展：新增 'holiday' 类型返回值
- `getLevel` 函数扩展：holiday → Level D
- `solveMonthlyBasePower` 扩展：计算 N_D（节假日小时数）

### 预填充的默认节假日（中国法定节假日）
- 元旦: 01-01 ~ 01-01
- 春节: 约 01-21 ~ 01-27 (农历，需用户调整)
- 清明节: 04-04 ~ 04-06
- 劳动节: 05-01 ~ 05-05
- 端午节: 约 06-22 ~ 06-24 (农历，需用户调整)
- 中秋节: 约 09-29 ~ 09-30 (农历，需用户调整)
- 国庆节: 10-01 ~ 10-07
