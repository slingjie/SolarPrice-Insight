# SolarPrice Insight 优化更新日志 (2026-01-27)

## 1. 核心架构重构 (Architecture Refactoring)
**目标**: 提升代码可维护性，解耦 UI 与业务逻辑。

-   **服务提取 (`services/priceCalculator.ts`)**:
    -   将原 `ComprehensivePriceCalculator.tsx` 中约 100 行的内联计算逻辑提取为纯函数服务。
    -   新增 `calculateAveragePrice` 函数，支持跨日计算、多月加权平均。
    -   新增 `timeToMinutes`, `getOverlapMinutes`, `getTimeSegments` 等通用时间处理工具函数。
-   **单元测试**:
    -   新增 `services/priceCalculator.test.ts`。
    -   包含 **21 个测试用例**，覆盖了跨日时间段（如 22:00-06:00）、无重叠、部分重叠、全覆盖等复杂场景，确保计算逻辑零回归。

## 2. 用户体验流程修复 (UX Flow Fixes)
**目标**: 消除用户操作中的“死胡同” (Dead Ends)，提升新手引导体验。

-   **空状态引导 (Empty State)**:
    -   在综合电价计算器中，当数据库无省份数据时，不再显示空白下拉框。
    -   显示“**暂无电价数据 - 前往导入**”的引导卡片，点击直接跳转至智能上传页面。
-   **智能上传解锁 (Smart Upload Unblock)**:
    -   在上传预览页，若检测到无“时间配置库”，不再卡死。
    -   新增“**一键生成默认配置**”按钮，自动创建“通用峰谷平”规则（含尖峰/高峰/平段/谷段/深谷），让新用户能顺利完成数据上传。

## 3. 交互效率提升 (Efficiency Improvements)
**目标**: 减少重复点击，修复数据格式兼容性问题。

-   **批量月份选择 (Batch Selection)**:
    -   在计算器月份选择区新增三个快捷按钮：
        -   **[全选]**: 选中当前省份下的所有可用月份。
        -   **[夏季]**: 智能筛选 6, 7, 8, 9 月。
        -   **[冬季]**: 智能筛选 12, 1, 2 月。
-   **Bug 修复**:
    -   修复了“全选”按钮生成的月份格式（`'01'`）与数据库实际格式（如 `'2024-01'`）不匹配导致选中失效的问题。现在按钮逻辑会动态读取并匹配实际数据格式。
